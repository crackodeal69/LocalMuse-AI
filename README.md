# LocalMuse AI

Local-first AI image studio designed to simplify personalized image generation.

The goal is to hide the complexity of dataset preparation, LoRA training,
image generation and editing behind a simple user-friendly interface.

## Planned Features

- Automated dataset captioning
- Dataset preparation and analysis
- Automated LoRA training
- AI-assisted prompt generation
- Local image generation
- Batch generation
- AI-based image quality assessment
- Local inpainting and image editing
- Hardware-aware configuration

## Project Status

🚧 Early development / Research

## Philosophy

Local-first. User-friendly. Open-source.

The user should not need to understand the underlying AI tooling
to create and use a personalized image model.
