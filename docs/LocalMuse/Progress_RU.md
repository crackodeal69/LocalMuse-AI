# LocalMuse AI - Журнал прогресса

Этот файл нужен для быстрого понимания текущего состояния проекта человеком.
Синхронизируй его с `Progress_EN.md` после каждого существенного изменения.

## Текущее состояние

**Этап:** рабочий прототип UI и pipeline

**Последнее обновление:** 2026-09-14

## Сделано

- Создан начальный Python-пакет в `localmuse/`.
- Добавлен `ImagePromptGenerator` в `localmuse/image_prompt.py`.
- Добавлена поддержка расширений JPG, JPEG, PNG, BMP и WEBP.
- Добавлено базовое извлечение метаданных изображения: имя файла, путь, формат,
  размеры и ориентация.
- Добавлено простое определение типа объекта по ключевым словам в имени файла:
  person, face, portrait и animal.
- Добавлено создание одноименного `.txt` с промптом рядом с поддерживаемым
  изображением.
- Добавлена пакетная обработка поддерживаемых изображений в папке.
- Добавлена генерация captions через Florence-2 с trigger token `nag_person`.
- Для пилотного датасета из 30 изображений созданы captions.
- Добавлена очистка captions от субъективных и идентифицирующих фраз.
- Все 30 captions очищены, исходные версии сохранены локально вне Git.
- Выполнен автоматический и визуальный review датасета; результаты записаны в
  `Dataset_Review_nag_person.md`.
- Добавлены тесты для портретного изображения, альбомного изображения и
  неподдерживаемого расширения.
- Добавлены тесты для одноименных TXT-файлов, сложных имен и обработки папки.
- Добавлен общий план проекта в `docs/LocalMuse/LocalMuse-AI_Project_Plan.md`.
- Создан рабочий LocalMuse UI поверх Forge API: генерация, Dataset & training,
  presets, русский/английский язык и светлая/тёмная тема.
- Добавлен выбор цвета глаз, пять базовых prompt-пресетов и локализованные
  `(i)`-подсказки к настройкам.
- Базовый checkpoint RealVisXL, cache Florence-2 и baseline LoRA-checkpoint-ы
  находятся в принадлежащем проекту дереве `models/`; бинарные файлы остаются
  исключёнными из Git.
- Жёстко заданные пути Forge и kohya в UI и вспомогательных скриптах заменены
  на настраиваемые переменные окружения с рабочими fallback-путями.
- API списка LoRA теперь включает checkpoint-ы из проекта и Forge; перед стартом
  обучения добавлена проверка существования базовой модели.

## Проверка

- Существующие тесты следует запускать командой:

  ```text
  pytest
  ```

- Последний запуск: `python -m pytest -q` завершился успешно: 13 тестов пройдено.
- Florence-2 проверена на RTX 3080 и создала 30 captions.
- В очищенных captions trigger встречается ровно один раз, пустых файлов и известных
  субъективных шаблонов не осталось.
- Все 30 кадров читаются, точных дублей нет; 29 кадров имеют размер менее 512 px
  по одной стороне и требуют учета при настройке обучения.
- Подготовлен baseline-конфиг LoRA для RealVisXL и отдельный output-каталог
  `dataset_v01`.
- Первый SDXL baseline-запуск завершен: 10 эпох, 3000 шагов, сохранены чекпоинты
  каждой эпохи и sample-изображения.
- Тесты покрывают генерацию промптов и создание одноименных TXT-файлов.
- Batch-файлы для повторного обучения и установки выбранного checkpoint в Forge
  описаны в `Generation_and_Training.md`.
- Добавлена основа preset-системы для будущего UI: обычный режим, Advanced-режим,
  Eyeful и сохранение пользовательских пресетов.
- В UI добавлен раздел `Dataset & training`: scan папки, запуск captions,
  подготовка versioned-копии под kohya и фоновый запуск LoRA.
- Добавлен временный единый batch-запуск `scripts\start_localmuse.bat` для Forge
  API и LocalMuse UI; `.exe` оставлен на финальный этап упаковки.
- UI проверен через браузер: Forge connected, пять пресетов, Dataset & training,
  русский язык, темы и tooltip-подсказки.
- Проверены пути: базовая модель и LoRA-checkpoint-ы находятся в проекте; внешние
  каталоги Forge/kohya можно переопределить через `LOCALMUSE_FORGE_ROOT`,
  `LOCALMUSE_FORGE_LORA_DIR` и `LOCALMUSE_KOHYA_ROOT`.

и запускать обучение профилями. Следующий шаг - progress/job panel, отбор
результатов и подготовка `dataset_v02`.
